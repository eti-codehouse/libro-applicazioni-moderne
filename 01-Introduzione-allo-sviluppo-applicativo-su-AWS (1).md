# Capitolo 1 - Introduzione allo Sviluppo Applicativo su AWS

## L'evoluzione dello sviluppo software nel cloud

Lo sviluppo software moderno richiede piattaforme in grado di garantire scalabilità, affidabilità, sicurezza e rapidità di rilascio. AWS mette a disposizione un ecosistema di servizi cloud che consente agli sviluppatori di concentrarsi sulla realizzazione delle funzionalità applicative anziché sulla gestione dell'infrastruttura.

## Gli strumenti fondamentali per gli sviluppatori AWS

Gli sviluppatori operano principalmente tramite AWS Management Console, AWS SDK e AWS CLI. Questi strumenti permettono di amministrare servizi, automatizzare processi e integrare direttamente le risorse cloud nel codice applicativo.

## La sicurezza come fondamento dell'architettura cloud

La sicurezza è un elemento centrale nello sviluppo su AWS. IAM consente di definire autorizzazioni granulari e applicare il principio del minimo privilegio, riducendo i rischi operativi e migliorando il controllo degli accessi.

## La gestione dei dati nelle applicazioni moderne

Amazon DynamoDB fornisce un database NoSQL ad alte prestazioni per i dati applicativi, mentre Amazon S3 offre uno storage a oggetti altamente scalabile per file, contenuti multimediali e archivi.

## Il modello serverless e AWS Lambda

AWS Lambda consente di eseguire codice senza gestire server, adottando un modello pay-per-use e permettendo la creazione di applicazioni altamente scalabili e orientate agli eventi.

## Architetture applicative moderne

Servizi come Amazon API Gateway, Amazon Cognito e AWS Step Functions consentono di realizzare API, gestire identità utente e orchestrare workflow complessi in architetture cloud-native.

## Automazione dell'infrastruttura con AWS SAM

AWS Serverless Application Model permette di descrivere l'infrastruttura come codice e automatizzare il deployment delle applicazioni serverless.

## Osservabilità e monitoraggio delle applicazioni

Amazon CloudWatch e AWS X-Ray forniscono funzionalità di logging, metriche e tracing distribuito per garantire visibilità operativa sulle applicazioni in produzione.

## Caso di studio: Polly Notes

L'applicazione Polly Notes integra Amazon Cognito, API Gateway, Lambda, DynamoDB, S3, Polly, CloudWatch e X-Ray per dimostrare una moderna architettura serverless su AWS.

## Conclusioni

I servizi AWS consentono di costruire applicazioni cloud-native sicure, scalabili e osservabili, fornendo gli strumenti necessari per affrontare l'intero ciclo di vita del software moderno.
