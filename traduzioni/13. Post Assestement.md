### Question 4
Ti è stato chiesto di scrivere un mapping template che verrà usato per interrogare una tabella Amazon DynamoDB. Il mapping template deve leggere il valore del parametro della method request dal path e passarlo a DynamoDB. Quale comando dovresti includere nel mapping template?

- $input.json(x)
- $input.json(x)
- $input.params(x)f
- $input.body
- $input.path(x)
### Answer 4
Un mapping template è uno script espresso in Velocity Template Language (VTL) e applicato al payload usando espressioni JSONPath.

> **Nota di studio:** la risposta corretta è `$input.params(x)`, che restituisce il valore del parametro della method request `x` cercandolo nel path, nella query string o negli header. `$input.path(x)` invece restituisce un oggetto del payload (body) tramite un'espressione JSONPath, non un parametro del path.
### Question 5
Hai configurato Amazon API Gateway come event source per la tua funzione Lambda. Di default, quanti retry tenterà Lambda per invocare la funzione?

- 1
- 2
- 4
- 3
### Answer 5
Lambda tenterà 2 retry.

> **Nota di studio:** i 2 retry automatici valgono per le invocazioni **asincrone** (es. S3, SNS, EventBridge). API Gateway invoca Lambda in modo **sincrono** e in quel caso Lambda non fa retry: è il client a dover ritentare. All'esame scegli "2" solo se la domanda è chiaramente impostata così.

### Question 7
Cosa è necessario per rendere un intero bucket disponibile a tutto il mondo? (Seleziona DUE.)

- Rendere la ACL del bucket public read.
- Usare chiavi gestite da Amazon S3 per le impostazioni di Server-side encryption a livello di bucket.
- Disabilitare "Block all public access" a livello di Account e di Bucket.
- Creare una configurazione CORS con AllowedOrigin MISSING e AllowedMethod 'GET'.
- Creare una bucket policy con effect "Allow", action ["s3\:GetObject"], Principal "\*" e una Resource con l'ARN del bucket S3.
### Answer 7
Per rendere un intero bucket disponibile a tutto il mondo è necessario creare una bucket policy con effect "Allow", action ["s3\:GetObject"], Principal "\*" e una Resource con l'ARN del bucket S3, e disabilitare "Block all public access" a livello di Account e di Bucket.

> **Nota di studio:** nella pratica la Resource deve puntare agli oggetti, cioè `arn:aws:s3:::nome-bucket/*`, perché `s3:GetObject` è un'azione a livello di oggetto.

### Question 16
Stai testando la tua funzione Lambda usando il comando AWS CLI Lambda invoke. Una volta testata con successo, la funzione verrà deployata e invocata in modo asincrono da un Amazon API Gateway. Quale dei seguenti comandi dovresti usare per testare la funzione?

- aws lambda invoke --function-name my-function --invocation-type RequestResponse --payload '\ "name": "test" \'
- aws lambda invoke --function-name my-function --invocation-type DryRun --payload '\ "name": "test" \'
- aws lambda invoke --function-name my-function --invocation-type Event --payload '\ "name": " test" \'
- aws lambda invoke --function-name my-function --payload '\ "name": " test" \'
### Answer 16
Quando invochi una funzione Lambda, fornisci alcune informazioni. Come minimo ti servono il nome della funzione, l'ARN della funzione o l'ARN parziale della funzione. ### Question 17
È stata configurata una DynamoDB Global Table tra tabelle nelle region N. Virginia e Sydney. ClientA nella region N. Virginia è configurato per scrivere sulla tabella in N. Virginia, mentre ClientB nella region Sydney è configurato per scrivere sulla tabella in Sydney. Entrambi i client aggiornano un item usando la stessa primary key e ClientA ha inviato l'aggiornamento appena prima di ClientB. Quale affermazione descrive meglio cosa succede?

- ClientA riceverà un errore.
- Entrambi gli aggiornamenti andranno a buon fine e alla fine l'aggiornamento di ClientA sarà presente in entrambe le tabelle.
- ClientB riceverà un errore.
- Entrambi gli aggiornamenti andranno a buon fine e alla fine l'aggiornamento di ClientB sarà presente in entrambe le tabelle.
### Answer 17
Entrambi gli aggiornamenti andranno a buon fine se viene usata la stessa primary key.

> **Nota di studio:** le Global Tables risolvono i conflitti con la regola **last writer wins**. ClientB ha scritto per ultimo, quindi alla fine in entrambe le tabelle ci sarà l'aggiornamento di ClientB (quarta opzione).

### Question 19
Stai pianificando di chiamare contemporaneamente delle API in esecuzione su due istanze Amazon EC2. Come configureresti la State Machine?

- Usare uno stato Parallel per avviare due Task simultanei.
- Usare uno stato Parallel per avviare due Activity simultanee.
- Usare uno stato Choice per avviare due Activity simultanee.
- Usare uno stato Choice per avviare due Task simultanei.
### Answer 19
AWS Step Functions usa workflow definiti come state machine. I workflow specificano come gli stati comunicano e come i dati vengono passati tra di essi. In questo caso si usa lo stato Parallel.

> **Nota di studio:** la risposta attesa è "Parallel + due **Activity**": le Activity sono il meccanismo con cui un worker esterno (es. codice su EC2) esegue il lavoro di un Task in Step Functions. Lo stato Choice serve a scegliere *un* ramo, non a eseguirne due in parallelo.
### Question 20
Stai progettando un'applicazione che permetterà a un utente di autenticarsi usando un identity provider esterno. È essenziale che vengano usate credenziali di sicurezza temporanee per accedere alle risorse di backend della tua applicazione in AWS. Quali risorse supportano la soluzione? (Seleziona DUE.)

- Creare un IAM Role per gli utenti autenticati.
- Creare un IAM Group per le identità autenticate.
- Creare una Amazon Cognito Identity Pool.
- Creare una Amazon Cognito User Pool.
- Creare un IAM Group per gli utenti autenticati.
### Answer 20
Usa le Amazon Cognito identity pool (federated identities) per creare identità univoche per i tuoi utenti e federarle con gli identity provider. Con una identity pool puoi ottenere credenziali AWS temporanee e con privilegi limitati per accedere ad altri servizi AWS.

> **Nota di studio:** le due risposte sono **Cognito Identity Pool** + **IAM Role per gli utenti autenticati** (l'Identity Pool assume quel ruolo per emettere le credenziali temporanee). Gli IAM Group non possono essere assunti.
