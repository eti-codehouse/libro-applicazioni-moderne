# Applicazione Polly Notes
Ciao, nel corso di questo corso vedrai noi istruttori fare riferimento a un'architettura di esempio chiamata applicazione Polly Notes. Questa applicazione è costruita utilizzando una varietà di servizi AWS e parleremo di ciascuno di essi durante il corso. Procediamo e visualizziamo il diagramma dell'architettura.

In questo diagramma puoi vedere che abbiamo diversi servizi come DynamoDB, Amazon API Gateway, Amazon S3, CloudWatch. Tutti questi servizi lavoreranno insieme per costruire un'applicazione. Questa applicazione è un sito web, e si accede a questo sito web usando un servizio chiamato Amazon Cognito.

Amazon Cognito è ciò che ti permetterà di autenticarti nel sito web. Una volta autenticato e sul sito web, puoi creare delle note. Queste note possono essere qualsiasi cosa: essenzialmente è testo in forma libera. E ciò che vogliamo fare con queste note è poterle salvare, quindi vogliamo poterle creare, aggiornare, cercare tra le note di uno specifico ID utente. Vogliamo poter eliminare le note e vogliamo poterle dettare. Ciò che intendo è che ogni volta che scrivi una nota con questa applicazione, genereremo un file audio usando Amazon Polly. Anche Amazon Polly è rappresentato qui nel diagramma. Tutte queste diverse funzionalità, la creazione, la lettura, l'aggiornamento, l'eliminazione e la ricerca, saranno gestite da funzioni Lambda.

Pensiamo quindi al flusso di funzionamento di questa architettura. Hai un utente che si autentica con Cognito. Quindi invierà una richiesta tramite il browser ad Amazon API Gateway, che sarà l'hosting dell'API posto davanti a una raccolta di funzioni Lambda. Queste funzioni Lambda sono ambienti di calcolo serverless che contengono codice che interagirà con un servizio DynamoDB di backend. Questa tabella DynamoDB conterrà tutte le note. Poi abbiamo anche un sito web che sarà ospitato in un bucket Amazon S3. E abbiamo un secondo bucket S3 in cui verranno memorizzati gli MP3 provenienti da Amazon Polly. Nel diagramma puoi vedere anche Amazon CloudWatch e AWS X-Ray, che saranno utilizzati per il monitoraggio e l'osservabilità di questa architettura.

E infine, un'ultima cosa da evidenziare in questo diagramma è AWS Serverless Application Model, o SAM, e imparerai come questo strumento può aiutarti a distribuire questa applicazione serverless in modo semplice e immediato.

Bene, per ora è tutto. Tieni d'occhio questo esempio durante il corso. Faremo riferimento a questa architettura man mano che procediamo con i moduli.
